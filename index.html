🔄

구글 스프레드시트 실시간 연동

구글 스프레드시트 링크를 등록하면, 교수님이 시트에서 단어나 대화를 수정할 때마다 깃허브 접속이나 코드 복사 없이 학생들 화면에 즉시 자동 반영됩니다.

연동 상태: 미연동 (기본 단어장 사용 중)
🔗 학생 배포용 자동 연동 링크

이 주소를 학생들에게 카카오톡이나 LMS에 공유하면, 학생들은 설정 없이 접속 즉시 교수님의 구글 시트를 자동으로 읽어옵니다.

📌 1분 구글 시트 링크 생성 방법:
  1. 구글 드라이브에서 어휘 목록이 담긴 스프레드시트를 엽니다.
  2. 상단 메뉴에서 [파일] ➔ [공유] ➔ [웹에 게시]를 클릭합니다.
  3. 형식을 '웹페이지'에서 [쉼표로 구분된 값(.csv)]으로 변경하고 [게시]를 누릅니다.
  4. 생성된 링크를 복사하여 위 입력란에 넣고 [동기화 실행]을 누르면 즉시 연결됩니다.
  5. (간편 대안) 시트 우측 상단 [공유]에서 '링크가 있는 모든 사용자(뷰어)'로 설정 후 일반 브라우저 주소를 넣으셔도 자동 변환됩니다.
